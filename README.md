Proyecto Backend - Revista Digital

Este proyecto es parte del segundo módulo del diplomado. Tiene como objetivo crear la base del backend para una revista digital utilizando Node.js, Express.js y MongoDB.

¿Qué contiene?

Un servidor básico creado con Express.js

Conexión a una base de datos MongoDB

Un modelo de Usuario que incluye: nombre, correo, contraseña y rol

Organización inicial de carpetas y archivos

¿Cómo iniciar el servidor?

Ejecuta npm install para instalar dependencias

Crea un archivo .env con las variables necesarias (puerto y URI de MongoDB)

Ejecuta node app.js para iniciar el servidor

Verás el mensaje: “Servidor corriendo en el puerto 3000”
